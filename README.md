# Project Postman — VGU Smart Locker (app side)

A phone app that lets a person open the right VGU locker, at the right locker point, at the right time — without a physical key.

This repo holds the **IT team (app)** work. The Server team owns the API and the database in a separate repo. The app talks to their API and decides nothing on its own.
