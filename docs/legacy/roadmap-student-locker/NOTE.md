# Why this board is here

This was the first board, for a **student storage locker**: log in with a student card, pick a locker point, open a locker. Exam-season mode. Two account types.

The product changed to a **parcel drop-off locker** on 2026-08-05, before any task was ticked and before any code was written. The board stood at `0 / 66`.

See [ADR 0003](../../adr/0003-parcel-locker-product.md) for what changed and why.

The live board is [docs/roadmap/README.md](../../roadmap/README.md).

**Task IDs here are dead.** The new board reuses `P0-01` and the rest. That reuse is a one-time allowance, recorded in ADR 0003, and it is safe only because nothing on this board was ever started. Do not read an ID here as the same task as an ID on the live board.
