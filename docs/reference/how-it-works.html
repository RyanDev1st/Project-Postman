The one place two paths exist

She scans the screen

The normal way

The square code on the cabinet does not say open box 04. It only says this cabinet, right now. Who she is comes from being signed in on her own phone.

If somebody copies itNothing happens. A photograph of that screen is worthless without her account.

She types the code

The backup way

The message also carries a short code she can type straight into the cabinet, with no app at all. It is there for the flat battery and the phone left at home.

If somebody copies itThe door opens. This code is the key — so it works once, it expires, and wrong guesses lock the box.

Three things the chart is quietly saying

The cabinet asks, it never decides

Every amber arrow starts at the server. The cabinet cannot choose a box or open a door by itself. A stolen cabinet opens nothing.

Nothing checks the box is full

There is no sensor. A closed door is all the system gets, so it trusts the driver. What it does keep is a trail: who closed which box, and when.

Nothing is free to guess

If the network drops halfway through step 6, the app cannot know whether the door opened. So it says so. It never shows a success it cannot prove.
