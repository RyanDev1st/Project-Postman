VGU Smart Locker · Project Postman

A parcel arrives.
Nobody waits for it.

A delivery driver leaves a parcel in a cabinet on campus. The student who owns it walks over whenever they like and takes it out with their phone. The two never have to meet.

The cabinet and the server

The cabinet has a screen, doors, and a sensor in each box. The server decides which door opens, and when.

A door opens. The parcel goes in.

The server picks a free box and opens that one door. The driver puts the parcel inside and shuts it.

A sensor inside the box checks that something is really there. Until it sees the parcel, nothing is recorded — so a driver who opens a door and walks away empty-handed cannot leave a delivery on the books that does not exist.

The two ways to open the door

Scan the screen

The normal way

The cabinet screen shows a square code that keeps changing. She points the app at it. The door opens.

The code on the screen does not say open box 04. It only says this cabinet, right now. Who she is comes from being signed in on her own phone.

If copiedNothing happens. A photo of the screen is useless without her account.

Type a code

The backup way

The message also contains a short code. She can type it straight into the cabinet, with no app at all.

This exists for the bad day — a flat battery, a phone left at home, an app that will not start. Without it, a dead phone traps a parcel.

If copiedThe door opens. This code is the key — so it works once, it expires, and wrong guesses lock the box.

These two are not equally safe, and that is the point of showing them side by side. Scanning is the front door. Typing a code is the spare key under the mat — worth having, kept short-lived on purpose.

Three things worth knowing

The cabinet asks, it never decides

The cabinet cannot choose a box or open a door on its own. It asks the server every time. A stolen cabinet opens nothing.

The sensor, not the door

A parcel counts as delivered when the sensor sees it — not when the door shuts. This removes a whole class of arguments about whether something was really left.

Never a false "done"

If the network drops halfway, the app does not know whether the door opened. So it says exactly that. It never shows success it cannot prove.

What this is not

  • Not paid. Free for students. No fees, no wallet, no card.
  • Not storage. You cannot rent a box to keep your own things in. A box holds a parcel until it is collected.
  • Not a student card system. No card, no scanning your ID. A phone number is the whole account.
  • Not the delivery company's problem. The driver needs no app, no account, and no training.
