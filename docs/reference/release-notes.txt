0.10.2 — you can sign in now, and the app stops closing itself

TWO THINGS, AND THE FIRST ONE IS THE ONE YOU HIT

**The app was closing itself, and that was a real crash.** You said it quit at
the "send code" part. It did: tapping Continue on the code screen took you to
the Home screen, and the Home screen died the moment it tried to draw the map.
The app was gone before it drew a single pixel of Home, so it looked like it
simply exited.

It was caused by the language switching added earlier the same day. To change
language without restarting the screen, the app hands every screen a
replacement Android "context" carrying Vietnamese or English. That replacement
was a detached one — it had the right words but no longer led back to the
screen it belonged to. The map asks the system for permission to show your
location, and to do that it has to find the screen it is running in. It
walked, found nothing, and threw. Fixed by wrapping the real screen instead of
replacing it. Vietnamese still switches everything, instantly, with no
restart — please check that too.

**Nothing in the sign-in flow could be typed into.** The phone box and the six
code boxes were pictures. Tapping them raised no keyboard, the Send code
button ignored whatever was in the field, and the only way back was the back
gesture, which from the sign-in screen closes the app. So the flow was a dead
end however you approached it.

Now: type a number, type a code, get in. Send code stays off until the number
is a real Vietnamese mobile. Continue stays off until there are six digits.
The code screen shows the number you actually typed, and going back to correct
a typo keeps it.

**There is still no server**, so nothing can say whether a code is the right
code. Any six digits will let you in. The screen says so in as many words, and
that message and the leniency are in this test build only — they cannot reach
a real user, and they disappear the day the sign-in call is wired.

WHAT TO TRY

1. Sign in. Type 912345678, then any six digits. You should land on Home with
   your parcel, the map and the walk.
2. Switch to Tiếng Việt in Settings, then walk the same path again.
3. Try to get the number wrong — five digits, or one starting with 2. Send
   code should stay off.

ONE DECISION STILL WAITING ON YOU

The design pass put the app on one spacing grid and one set of corner radii.
Four values in the mock-up sit on neither — the card's corner is 18 and its
padding 14, and the bottom bar's padding is 5 with a 3 gap; the app uses 22,
12, 4 and 2. Everything else matches the mock-up exactly. It is settled in
favour of the grid for now, because the mock-up's own values were eyeballed.
Say the word if you would rather have the mock-up's numbers back.
