0.12.0 — there is a server now, and the parcels in this build are real

CHECK THIS FIRST: Settings → Version should say 0.12.0. If it says anything
else the install did not take, and nothing below will be there.

WHAT CHANGED

Every build before this one was talking to nothing. Signing in took any six
digits. The parcels on the Home screen were invented by the app — boxes 04 and
07 at the back gate, which existed only inside the phone. A good QR moved you
to a door screen and no metal was ever asked to move.

All of that is gone. There is a real server now, and this build talks to it.

  - The number you type gets a real one-time code, and a wrong code is refused.
  - Home lists the parcels the server is actually holding for you. If the
    server has none, it says so instead of inventing two.
  - Scanning a cabinet asks the server to open a box, and the server decides
    whether it will.

WHAT IS STILL NOT REAL

  - NO DOOR MOVES. A laptop stands in for the cabinet's electronics and prints
    what it would have done. That is the honest limit of this build.
  - NO NOTICE ARRIVES. Nothing pushes a message to the phone yet, so when a
    parcel is dropped for you the phone does not ring. Open the app and it is
    there. That is the next phase, not a fault.
  - The one-time code is printed in the laptop's terminal, not sent by SMS.

BEFORE IT WILL REACH ANYTHING

The server runs on a laptop, on the wifi, with a certificate it made itself.
Two things follow, and both are one-time:

  1. The phone must be on the SAME WIFI as the laptop.
  2. The phone must install config/dev-cert/locker.crt once, under
     Settings → Security → Encryption & credentials → Install a certificate
     → CA certificate.

Without step 2 every screen will say it cannot reach the server. The app is
right to refuse: nothing signed that certificate until you say so.

THE WHOLE RUN, IN ORDER

docs/reference/real-world-test.md has the ten steps and what to look at for
each. The short version: register on the phone, drop a parcel to your own
number on the cabinet screen, then collect it by scanning the cabinet's QR.

WHAT IS WORTH REPORTING

Anything the app says that a person outside this team would not understand.
How long the one-time code took. Whether the QR read on the first try, and
from how far away. Whether any part of a real name or phone number was
readable on the cabinet screen — that one matters most, because that screen is
public and anybody can stand behind you.
