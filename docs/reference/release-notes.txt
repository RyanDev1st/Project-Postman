0.11.0 — the scanner has a camera in it now

CHECK THIS FIRST: Settings → Version should say 0.11.0. If it says anything
else, or there is no Version row at all, the install did not take and nothing
below will be there. That row is new in this build, and it exists because
until now there was no way to tell which build you were holding.

THE SCAN SCREEN WAS A PICTURE OF A SCANNER

You said the QR scanning was a black screen that never asked for the camera.
That is exactly what it was. The screen had a dark box, four orange corners
and a sweep travelling down it, and nothing behind any of it — no camera, no
reader, no permission request. It looked finished and did nothing, which is
the worst way for a screen to be unfinished. The button that opens it from the
Home bar was also wired to nothing.

Both are real now. The app asks for the camera when you open the scan screen,
shows what the camera sees, and reads the QR off it.

WHAT TO TRY

There are four codes to point it at, and each should give a different answer.
They are laid out on a page with what to expect from each:

  https://claude.ai/code/artifact/c4d08547-d225-4ef3-aada-ce0deed2a14f

The live one has to come from the cabinet screen, because a code stops being
true after 60 seconds:

  cd "src\cabinet"
  python -m http.server 8080

Then open http://localhost:8080 on a laptop and point the phone at it. It
draws a new code every 30 seconds.

WHICH CABINET YOU SCANNED NOW DECIDES WHAT HAPPENS

  a live code where a parcel is yours     the door screen, box 04
  a live code at any other cabinet        "Nothing waiting here."
  an expired code, either cabinet         "Code expired. Scan again."
  anything else, a poster or a website    nothing at all, it keeps looking

The expired case says the same sentence whichever cabinet it names. That is
deliberate: the other way round, somebody with a dead code could work out
where your parcels are without ever holding a live one.

A refusal does not stop the camera. The sentence appears, the viewfinder keeps
running, and the cabinet draws a fresh code every 30 seconds — so "scan again"
is advice the screen lets you follow.

WHAT IS STILL PRETEND

Boxes 04 and 07 at the back gate. There is no server yet, so the app cannot
ask anything about real parcels, and a good code moves you to the door screen
without any metal moving. Signing in still takes any six digits.

If the camera preview is black in THIS build, that is a real fault and worth
reporting — say which phone.
